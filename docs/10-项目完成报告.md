# 第二阶段项目完成报告

## 基于 MongoDB 的在线问卷系统

## 1. 项目目标

第二阶段在原有系统上增加三类能力：

1. 建立可复用的题目库，支持直接建题、从问卷另存、跨问卷复用和按用户共享。
2. 建立题目版本历史，修改时由用户决定创建新版本或覆盖当前版本；已经加入问卷的题目快照不受影响。
3. 建立题目 ID 查询和跨问卷统计，能够返回使用问卷 ID，并按总体、问卷和版本分析同一道题的答题情况。

## 2. 系统设计

新增 `question_bank/` 模块负责题目族、别名、共享、版本和使用关系；新增 `analytics/cross_survey_service.py` 负责跨问卷分析
主要流程：

```text
直接建题 / 问卷题目另存
→ 题目族与版本
→ 按用户共享
→ 加入草稿问卷并复制快照
→ 发布、填写、提交
→ 单卷统计或跨问卷统计
```

版本编辑支持两种保存方式：

- 创建新版本：旧版本保留，新版本记录 `parentVersionId`。
- 直接修改：覆盖所选版本，不新增版本；问卷中的快照仍然不变。

## 3. MongoDB 设计

系统继续使用 `users`、`surveys`、`responses`，新增 `question_bank`，共四个业务集合。

`question_bank` 使用“题目族 → 版本”两层结构：

```text
question_bank
├─ ownerId / familyKey / title
├─ aliases[] / aliasKeys[]
├─ sharedWith[]
├─ currentVersionId
└─ versions[]
   ├─ id / number / fingerprint
   ├─ title / type / options[] / config{}
   ├─ parentVersionId
   └─ createdAt
```

关键设计：

- 一个题目族只保存一份文档，共享关系放在 `sharedWith[]`，不复制整份题库。
- 版本保存完整题目内容，任意版本都可以被不同问卷选择。
- 问卷题目保存快照和 `sourceBankId`、`sourceVersionId`，题库后续修改不会改变旧问卷。
- 从问卷另存到题库时，来源 ID 会回填到原问卷题目，保证原问卷也能参与跨问卷统计。
- 跨问卷查询使用多键索引。
- MongoDB Validator 要求题目族至少包含一个完整版本，缺少 `versions` 的文档会被拒绝。

完整 Schema 和索引见 `docs/08-MongoDB-Schema.md`。

## 4. 校验设计

本阶段增加的校验主要是数据关系和权限：

- 题目首次进入题库时检查题型、题干、选项和配置。
- 同一题目族用规范化题干和内容去重。
- 创建版本时记录父版本；直接覆盖时保持版本 ID 不变。
- 被共享用户只能查看、引用和分析自己的问卷，不能修改原题目族。
- 题目 ID 查询必须解析到当前用户可访问的题目族或版本。
- 原有多选数量、文本长度、数字范围、必填和跳转规则校验继续执行。

## 5. AI 使用过程

AI 帮助生成了题目库 repository、service、路由、MongoDB Validator、版本页面、题目 ID 查询页、跨问卷统计模块和测试初稿。

我调整的设计包括：

**1、 ai初版使用了“题目族-变体-版本”三层结构，比较混乱，我改使用“题目族 → 版本”，取消题目变体第三层。
2、修改了由用户版本更改，由单一创建新版本改为选择创建版本或直接覆盖。
3、跨问卷统计限制在当前用户自己的问卷，避免共享题目导致答卷泄露。
4、分析结果修改的更加全面，同时提供问卷 ID、总体分析、分问卷分析和分版本分析。**

完整提示词、生成结果和修改记录见 `docs/11-AI使用日志.md`。

## 7. 遇到的问题
1、题库编辑原来只能创建新版本，不够灵活。后来增加了“创建新版本 / 直接修改”两种保存方式，让用户自己决定。
2、从问卷把题目另存到题库后，原问卷没有来源信息，跨问卷统计找不到它。后来在保存成功后自动回填 sourceBankId 和 sourceVersionId，保证原问卷也能被追踪。
3、同一道题在不同问卷里的本地题目 ID 都不一样，不能直接拿一个 ID 去查所有答卷。后来解决方式是先通过题库来源字段找到对应问卷，再使用每份问卷自己的本地题目 ID 读取答案。
4、题目共享后，不能直接统计所有使用问卷，会让题目所有者看到其他用户的答卷数据。因此跨问卷统计限制为当前用户自己的问卷，避免通过共享题目泄露数据。
6、一开始跨问卷分析只有总体结果，信息不够全面。后来补充了分问卷分析和分版本分析，并增加选择题分布、文本高频答案、数字平均值、中位数、分位数和区间分布等内容。
