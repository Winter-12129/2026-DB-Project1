# 测试案例与测试结果

测试日期：2026-10-20  
测试对象：基于 MongoDB 的问卷系统  
测试环境：Windows、Python 3.12.8、MongoDB 8.3.11

## 1. 测试范围

测试覆盖账号、问卷管理、题目、跳转规则、公开填写、重复提交和统计七个部分。测试分为三层：

1. `tests/test_first_feature.py`：不依赖外部数据库，使用内存数据库替身验证业务逻辑。
2. `tests/api_live_test.py`：启动真实 Flask 服务和临时 MongoDB，通过 HTTP 页面和 JSON API 走完整流程。
3. 真实 MongoDB 冒烟测试：验证 PyMongo 查询、索引、答卷写入和统计读取。

测试使用的临时数据库为 `survey_system_api_test`，测试结束后会删除，不修改日常使用的 `survey_system` 数据库。

## 3. HTTP 测试流程

`tests/api_live_test.py` 不是 Flask 内部测试客户端，而是通过真实 HTTP 请求访问运行中的 Web 服务。执行流程如下：

1. 请求 `/register`，读取页面中的 CSRF token，提交注册表单。
2. 请求 `/login`，登录后进入 `/surveys`。
3. 请求 `/surveys/new`，创建一份允许重复提交的问卷。
4. 检查创建后的响应地址是否为 `/surveys/<问卷ID>`，并确认页面包含“题目与跳转”。
5. 连续添加单选、多选、文本、数字四类题目。
6. 给单选题添加“选 A 跳到数字题”的规则。
7. 发布问卷，打开 `/survey/<分享码>`。
8. 调用 `POST /api/v1/surveys/<分享码>/responses` 提交两条不同路径的答卷。
9. 用重复的提交 token 再请求一次，确认返回幂等结果。
10. 读取 Mongo 中的两份答卷，检查 `visitedQuestionIds`。
11. 请求整卷统计和单题统计页面，检查题型和平均值是否出现。

测试输出中的每个步骤均返回 `[OK]`，最终输出：

```text
HTTP 测试全部通过。
```

### 复现方式

测试脚本要求 Flask 运行在 `5001` 端口，并使用独立的测试数据库。可以复用本机已经启动的 MongoDB，只要不要和日常数据库同名：

第一个终端启动 Flask：

```powershell
cd "D:\DaSE\数据管理系统\Project\survey-system"

$env:MONGO_URI = "mongodb://127.0.0.1:27017"
$env:MONGO_DB_NAME = "survey_system_api_test"
$env:SECRET_KEY = "api-live-test"

python -c "from app import create_app; create_app().run(host='127.0.0.1', port=5001, debug=False, use_reloader=False)"
```

第二个终端执行测试：

```powershell
cd "D:\DaSE\数据管理系统\Project\survey-system"

$env:SURVEY_TEST_BASE_URL = "http://127.0.0.1:5001"
$env:SURVEY_TEST_MONGO_URI = "mongodb://127.0.0.1:27017"
$env:SURVEY_TEST_DB_NAME = "survey_system_api_test"

python tests/api_live_test.py
```

脚本结束时会删除 `survey_system_api_test`，不会删除 `survey_system` 中的正式数据。
