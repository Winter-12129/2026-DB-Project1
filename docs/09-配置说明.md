# 配置说明

## 1. 运行环境

本项目当前使用：

| 组件 | 版本 |
|---|---|
| Python | 3.12.8 |
| Flask | 3.1.2 |
| PyMongo | 4.18.1 |
| Jinja2 | 3.1.6 |
| MongoDB | 8.3.11 |

前端使用原生 HTML、CSS 和 JavaScript，不需要 Node.js 构建步骤。

## 2. 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `SECRET_KEY` | 开发用默认值 | Flask 会话签名密钥，生产环境必须替换 |
| `MONGO_URI` | `mongodb://127.0.0.1:27017` | MongoDB 连接地址 |
| `MONGO_DB_NAME` | `survey_system` | 业务数据库名 |

配置入口在 `config.py`。数据库连接和索引在 `common/db.py` 中初始化。

## 3. 首次运行

在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

$env:SECRET_KEY = "请换成随机字符串"
$env:MONGO_URI = "mongodb://127.0.0.1:27017"
$env:MONGO_DB_NAME = "survey_system"

.\.venv\Scripts\python.exe app.py
```

打开：

```text
http://127.0.0.1:5000
```

如果已经全局安装 Flask 和 PyMongo，也可以直接执行 `python app.py`。

## 4. MongoDB

启动 MongoDB 后再启动 Flask。应用启动时会：

- 连接 `MONGO_URI`。
- 选择 `MONGO_DB_NAME`。
- 检查连接。
- 创建用户、问卷和答卷需要的索引。

MongoDB 是独立进程，`pip install pymongo` 只安装 Python 客户端，不会启动数据库服务。

## 5. 测试配置

单元测试：

```powershell
python -m unittest discover -s tests -v
```

HTTP 测试需要 `requirements-dev.txt` 中的 `requests`。测试脚本要求 Flask 运行在 `5001`，并使用独立数据库：

```powershell
$env:MONGO_URI = "mongodb://127.0.0.1:27017"
$env:MONGO_DB_NAME = "survey_system_api_test"
$env:SECRET_KEY = "api-live-test"

python -c "from app import create_app; create_app().run(host='127.0.0.1', port=5001, debug=False, use_reloader=False)"
```

另一个终端：

```powershell
$env:SURVEY_TEST_BASE_URL = "http://127.0.0.1:5001"
$env:SURVEY_TEST_MONGO_URI = "mongodb://127.0.0.1:27017"
$env:SURVEY_TEST_DB_NAME = "survey_system_api_test"

python tests/api_live_test.py
```

测试结束后脚本会删除 `survey_system_api_test`，不会删除正式的 `survey_system` 数据。

## 6. 常见问题

### pip 下载 Flask 时 SSL EOF

这是 pip 到 PyPI 的网络连接问题，不是项目代码问题。可以选择：

1. 使用已经安装 Flask/PyMongo 的全局 Python。
2. 创建 `python -m venv --system-site-packages .venv-shared`。
3. 使用国内镜像：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 无法连接 MongoDB

确认 MongoDB 已启动并监听 `27017`：

```powershell
Get-NetTCPConnection -LocalPort 27017 -State Listen
```

没有输出时先启动 MongoDB，再运行 Flask。

### 页面样式没有更新

浏览器可能缓存了旧 CSS。停止 Flask 后重新启动，并在浏览器中按 `Ctrl + F5`。

## 7. 配置边界

- `SECRET_KEY` 不要写进公开仓库。
- 不要把真实 MongoDB 密码提交到代码中，生产环境应通过环境变量或密钥管理系统提供。
- 当前开发默认使用 `127.0.0.1`，如果部署到服务器，需要按实际网络和反向代理配置调整。
