# AI 使用日志（第二阶段）

使用工具：Codex
记录范围：第二阶段功能性需求对话
记录日期：2026-10-22

## 日志 1：常用题目库

### Prompt

> 现在开始第二阶段优化，新增需求是希望可以保存常用题目，方便以后重复使用。用户可以创建题目并保存，创建新问卷时可以从已有题目中选择，一个题目可以被多个问卷使用。我的想法是新增一个题目库，在写入问卷文档的同时在题目库中写入这道题，同时注意去重。题目库也可以通过前端管理题目，把题目加入题库，从题库中选题。类似“姓名”和“你的名字是”是否可以合并？相同题干如果选项或者题型不一样，可以在题目下保存不同分支。

### 得到的内容

AI 实现了 `question_bank` 集合和对应模块，包括：

- 用户直接新建常用题。
- 从问卷另存题目到题库。
- 从题库选择题目加入草稿问卷。
- 规范化题干和内容指纹去重。
- 问卷保存完整题目快照和题库来源 ID。
- 题目别名和题目族管理页面。

### 修改

- “姓名”和“你的名字是”没有直接使用模糊匹配自动合并，而是提供人工别名，避免误合并。
- 题目库只保存题目定义，问卷中保存快照，防止题库修改影响已经做好的问卷。
- 从问卷另存题目后补充来源字段回填，使原问卷也能被追踪。

## 日志 2：题目共享

### Prompt

> 第二个新增需求，用户反馈希望可以把题目共享给其他用户，其他用户可以在自己的问卷里使用这些题目。共享后仍然可以继续使用同一个题目。我的想法是把题库文档接入每一个用户，使他们都能查看调用。

### 得到的内容

AI 增加了：

- 题目族的 `sharedWith` 用户 ID 数组。
- 按用户名共享和取消共享。
- “共享给我的题目”页面区域。
- 被共享用户从题库选择版本并加入自己的问卷。
- 共享权限测试。

### 修改

- 没有给每个用户复制一整份题库文档，而是用 `sharedWith` 建立访问关系。
- 被共享用户只能查看、引用和分析自己的问卷，不能修改、恢复或删除原题目族。
- 已经加入问卷的题目继续使用快照，取消共享不会改变已有问卷。

## 日志 3：题目版本历史

### Prompt

> 希望修改题目时不要影响已经做好的问卷，已经发布的问卷里的题目不能被修改。同时可以看到题目的历史版本，知道新题是从哪个题改来的，可以恢复旧版本。同一个问题的不同版本可以同时存在，也可以在不同问卷中使用。

### 得到的内容

AI 实现了：

- `versions[]` 保存题目历史。
- `parentVersionId` 记录版本来源。
- 基于旧版本创建新版本。
- 恢复旧版本并切换当前版本指针。
- 在问卷中选择任意题库版本。
- 已发布问卷题目只读测试。
- 前端版本时间线，最新版本优先展示。

### 修改

- 恢复旧版本只切换 `currentVersionId`，不删除新版本。
- 问卷继续保存版本快照，题库新增或恢复版本都不会改写旧问卷。

## 日志 4：确定题目版本结构

### Prompt

> 取消变体的结构，无论题干还是选项改变都算作一个新版本，另外，恢复旧版本时需要先保存这个新版本，再回到上一个版本。

### 得到的内容

AI 将题库模型收敛为“题目族 → 版本”两层，不再保留题目变体第三层。版本按 `number` 倒序展示，最新版本在前，并显示“基于 vN”和“当前版本”。

### 修改

- 题干、题型、选项或配置发生变化，都直接形成新版本。
- `currentVersionId` 只表示当前默认版本，不限制其他历史版本被问卷使用。
- 恢复操作只切换当前版本，不需要复制出第三层对象。

## 日志 5：修改方式、题目 ID 查询与跨问卷统计

### Prompt

> 最后一个需求，修改时可以决定是否创建新版本。希望能查看某个题被哪些问卷使用，最好能返回问卷 ID，并在题目库构建一个 ID 查询系统。查看结果时，用户不想只看自己问卷的数据，还想看到某一道题在所有问卷中的回答情况。例如“你的年龄”在很多问卷里都用了，希望看到所有问卷里年龄的总体分布。预期是直接访问题目 ID，统计总答题数据，以及在不同问卷下的答题分析，这个分析要尽量全面、有价值。

### 得到的内容

AI 实现了：

- 版本编辑页选择“创建新版本”或“直接修改”。
- 题目族 ID、版本 ID、问卷内题目 ID 三种查询方式。
- `/question-bank/lookup` 查询页面。
- `/question-bank/insights/<题目ID>` 和 JSON API。
- 使用问卷 ID、本地题目 ID 和版本使用情况。
- 总体统计、分问卷统计和分版本统计。
- 数字题平均值、中位数、标准差、分位数和区间分布。
- 文本题答案数量、高频答案和可识别数字分析。
- 选择题选项次数和比例。
- 单卷统计页直达跨问卷分析的入口。

### 修改

- 直接修改只覆盖题库版本，问卷中的题目快照不变。
- 跨问卷统计只查询当前用户自己的问卷，避免共享题目后看到其他用户的答卷。
- AI 初版漏掉了“问卷题目另存到题库”后的反向来源回填，导致原问卷不进入使用列表；通过测试发现后已修正。
- 查询使用 `{ ownerId, questions.sourceBankId }` 索引定位候选问卷，再读取各问卷自己的本地题目 ID。
