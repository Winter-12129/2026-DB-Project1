数据口径

  • “使用问卷”只包含当前登录用户自己的问卷，避免题目共享后泄露其他用户的答卷数据。
  • 跨问卷统计通过 `sourceBankId + sourceVersionId` 映射到每份问卷自己的题目 ID，再读取该题答案。
  • 访问人数按 `visitedQuestionIds` 计算，回答人数按实际答案计算；被跳转规则绕过的题目不会进入分母。
  • 同一份问卷如果使用了同一题目的多个版本，会产生多条使用记录；去重答卷按“问卷 + 答卷”计算。
  • JSON API：/api/v1/question-bank/insights/{{ reference }}
