# 基于 MongoDB 的问卷系统

这是一个基于 Flask + MongoDB 的在线问卷系统，支持题目跳转、匿名填写、重复提交控制和自动统计。

当前完成：用户账号、问卷创建管理、题目与条件跳转、公开填写、重复提交策略和统计结果。

## 已实现

- 用户注册。
- 用户登录、退出。
- 登录后使用当前账号创建问卷，填写标题、说明和是否允许匿名填写。
- 创建问卷后直接进入题目与跳转管理页。
- 只查询当前登录用户创建的问卷。
- 自动生成问卷分享码和 `/survey/<分享码>` 链接。
- 发布问卷、设置截止时间、关闭问卷。
- 打开管理页复制分享链接。
- 打开公开链接时根据“是否允许匿名填写”决定是否要求先登录。
- 设置是否允许同一人重复填写。
- 添加、删除题目。
- 直接在题目库新建常用题，也可把问卷题目另存到题目库，并从题库选择到问卷。
- 题目库按题干和内容指纹去重，题目族下保存并显示历史版本。
- 修改题干、题型、选项或配置时，可以创建新版本，也可以覆盖所选版本；已发布问卷仍只读。
- 可以把题目族按用户名共享给其他用户，被共享用户可在自己的问卷中使用但不能修改原题目。
- 支持用题目族 ID、版本 ID 或问卷内题目 ID 查询使用问卷和问卷 ID。
- 支持一道题跨多份问卷的总体统计、分问卷分析和分版本分析；选择题、文本题和数字题都有对应分析。
- 单选题、多选题、文本题、数字题。
- 多选题设置最少和最多选择数量。
- 文本题设置最少和最多字数。
- 数字题设置最小值、最大值和是否只能填整数。
- 每道题设置是否必选。
- 配置单选、多选、数字题的跳转规则。
- 跳转规则设置来源题、条件、目标题和优先级。
- 公开链接逐题填写，根据答案自动跳转。
- 服务端重新计算访问路径，只校验实际访问到的必填题。
- 保存答卷、答案和 `visitedQuestionIds`。
- 提交令牌保证双击或网络重试不会重复写入。
- 未允许重复填写时，登录用户或匿名会话只能提交一次。
- 打开问卷统计页，并校验当前用户是否为问卷所有者。
- 查看整卷统计或指定题目的统计。
- 单选题显示选项人数和回答总人数。
- 多选题显示每个选项被选择的次数。
- 文本题显示全部文本答案，并识别数字计算平均值。
- 数字题显示平均值、最小值和最大值。

## 用户数据

`users` 集合中的用户文档至少包含：

| 字段 | 含义 |
|---|---|
| `_id` | MongoDB 自动生成的用户 ID |
| `username` | 用户名，唯一 |
| `passwordHash` | 密码哈希，不保存明文密码 |
| `createdAt` | 注册时间，UTC |

## 数据库接口放在哪里

| 文件 | 负责的数据 |
|---|---|
| `common/db.py` | MongoDB 连接、集合入口和索引 |
| `auth/repository.py` | `users` 集合的插入和查询 |
| `surveys/repository.py` | `surveys` 集合的创建、按所有者查询、按 ID 查询、按分享码查询、状态和截止时间更新 |
| `publishing/service.py` | 发布、设置截止时间、关闭、公开访问状态判断 |
| `questions/service.py` | 题目的添加、删除、答案校验和发布前检查 |
| `question_bank/repository.py` | `question_bank` 集合的题目族、共享用户和版本读写 |
| `question_bank/service.py` | 去重、别名归并、版本创建与恢复、共享权限和来源快照 |
| `logic/service.py` | 跳转规则、路径求值、服务端路径重放 |
| `responses/repository.py` | `responses` 集合的答卷写入 |
| `responses/service.py` | 提交令牌、身份去重和答卷保存 |
| `analytics/repository.py` | 按问卷版本读取答卷 |
| `analytics/cross_survey_service.py` | 题目来源映射、跨问卷统计、分问卷和分版本分析 |
| `analytics/service.py` | 整卷和单题统计计算 |

业务代码不直接写 MongoDB 查询，而是调用对应模块的 repository。

## 运行

先确认 MongoDB 已经启动。然后在本项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

$env:SECRET_KEY = "请换成一个随机字符串"
$env:MONGO_URI = "mongodb://127.0.0.1:27017"
$env:MONGO_DB_NAME = "survey_system"

.\.venv\Scripts\python.exe app.py
```

浏览器打开：

```text
http://127.0.0.1:5000
```

如果已经有可用的全局 Flask 和 PyMongo，也可以直接从第三步的环境变量开始，用 `python app.py` 运行。

## 测试

测试使用内存中的数据库替身，不要求本机 MongoDB 正在运行：

```powershell
python -m unittest discover -s tests -v
```

HTTP 集成测试需要 `requests`，它列在 `requirements-dev.txt` 中。具体启动方式见 `docs/06-测试案例与结果.md`。

测试覆盖：

- 注册、登录、创建问卷、查看统计页。
- 两个用户之间的问卷隔离。
- 重复用户名被拒绝。
- 密码以哈希形式保存。
- 问卷的 `ownerId` 来自当前登录用户。
- 分享码生成和公开链接格式。
- 发布、截止时间、关闭流程。
- 非匿名问卷打开链接时跳转登录，登录后返回问卷。
- 匿名问卷链接不登录也能打开。
- 其他用户不能管理问卷。
- 空问卷不能发布。
- 单选题、多选题、数字题的跳转规则。
- 跳过的必填题不阻塞提交。
- 服务端重放路径，丢弃未访问题目的答案。
- 多选最少/最多数量校验。
- 数字范围、整数校验。
- 题目库直接建题、去重、版本历史、覆盖修改、恢复、别名和跨问卷复用。
- 题目 ID 查询、使用问卷 ID 返回和跨问卷总体统计。
- 题目共享给第二个用户，被共享用户可以查看并使用，但不能修改原题目。
- 答卷保存访问路径。
- 同一提交令牌幂等返回，不重复保存。
- 不允许重复填写时阻止同一身份第二次提交。
- 允许重复填写时保存多份答卷。
- 单选题、多选题、文本题和数字题的统计。
- 整卷统计和单题统计。

## 当前边界

当前阶段不包含：

- 题目编辑和拖动排序（目前支持添加和删除）。
- 多条条件组合的图形化编辑器（数据结构支持 `clauses`，当前界面一次配置一个条件）。
- 跳转到页面或返回上一题。
- 图表、Excel 导出和文件上传。
- 答卷逐条删除和恢复。
- 跨问卷统计当前按需读取答卷；超大数据量时可进一步增加离线汇总集合。

公开链接现在可以真正填写；提交后答卷会写入 `responses` 集合，统计页会按当前问卷版本自动生成结果。

## 填写权限约定

- `allowAnonymous = true`：链接可以直接打开，不强制登录。
- `allowAnonymous = false`：未登录用户打开链接会先跳到登录页，登录成功后返回该链接。

这是对“是否允许匿名填写”和“填写者需要先登录”两条要求的组合实现。默认创建时不允许匿名，保证默认行为是必须登录。
